## Устранённые предметные ошибки

1. PD.03 хранит **количество оборудования** и **спрос в единицах результата за период**. PD.09 использует вторую величину, не подменяет её числом станков. При выборе точного CapacityModel объем за горизонт сверяется с исходной потребностью, единицей и календарным периодом. Смешанная оценка номинальной мощности без подтверждённого выпуска, инвентаризация, диапазон спроса, пользовательские единицы и неподтверждённые преобразования не проходят как сопоставимые автоматически.
2. PD.09 теперь требует достоверно указанную основную цену или ставку выбранного способа. Известная доставка при неизвестной стоимости товара не считается полной ценой покупки; известный депозит не заменяет арендную ставку. Явный ноль допустим и отличается от незаполненной суммы.
3. PD.09 подтверждает итоговый выбор только среди двух/трёх альтернатив с одинаковыми валютой, сроком, объёмом и единицами результата. Несопоставимые способы остаются сохраняемыми как незавершённое решение без утверждения победителя.
4. Точка равенства не рассчитывается на пустом или лишённом основной ставки сценарии; сообщения в интерфейсе переведены на понятный русский язык. Известные статьи затрат не выдаются за полный TCO.
5. Точная связка и редакции исходных PD.01/03/04 остаются неизменными. Новый Result сохраняет сведения о сопоставимости отдельно; старые исторические Results не правятся задним числом.
6. Документация сайта актуализирована для публичной временной вкладки и настоящего T2 Host/Kernel/Workspace/Exchange с одной конечной HTTPS-сборкой.

## Отрицательные и положительные условия приёмки

| Проверка | Ожидаемое поведение |
| --- | --- |
| PD.03 спрос 120 изделий в месяц, PD.09 36 месяцев и 4 320 изделий | Сопоставимо |
| При тех же условиях PD.09 3 600 изделий | Блокировка финального выбора, сохранение на уточнение допускается |
| Два станка вместо количества выпуска | Не считать объёмом результата |
| Аренда 24 мес./2 400 ед. против покупки 36 мес./3 600 ед. | Несопоставимо, окончательный выбор блокируется |
| Покупка RUB и аренда USD | Несопоставимо, окончательный выбор блокируется |
| Полностью пустые деньги, либо только доставка при неизвестной цене товара | Точка равенства не рассчитывается |
| Явно известная нулевая основная стоимость | Не считается пропуском, остальные статьи остаются отдельно проверяемыми |
| Отсутствует PD.03 при самостоятельной услуге | Можно оценить отдельно, если варианты между собой сопоставимы |
| Сохранённая редакция PD.04 изменилась | Старое решение не привязывается автоматически к новой редакции |

## Дальнейшая предметная граница

Исправление PD.03/09 не создаёт автоматического выбора «самого выгодного» при недостатке существенных расходов, отсутствующих подтверждениях совместимости или неизвестной доступности. Полноценная история передачи товара другому владельцу остаётся отдельной сквозной задачей на существующем T2 Exchange. Не расширять 21-сервисный каталог ради формального количества.
