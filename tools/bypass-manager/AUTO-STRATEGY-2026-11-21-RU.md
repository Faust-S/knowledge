# Bypass Manager 0.5 Alpha: автономная адаптация TLS в Windows

## Основной путь

Распакуйте весь ZIP, запустите `Bypass-Manager.exe` и нажмите **«Включить»**. Приложение запросит права Windows для работы оригинального WinDivert, проверит встроенные компоненты `winws2` и запустит собственный локальный фильтр. VPN, Amnezia и внешний сервер для этого режима не нужны. Кнопка **«Выключить»** останавливает только собственный процесс Bypass Manager.

Кнопка **«Скорость и регион»** выполняет отдельную проверку внешнего IPv4 и HTTPS-передач именно программы. Кнопка **«Отчёт»** сохраняет обезличенные результаты, не выгружая посещённые домены, IP, локальные пути и настройки VPN.

## Что добавлено

Оригинальный `winws2` продолжает определять проблемные домены по повторным отказам TCP/TLS. Изучение отказов требует входящих и исходящих TCP-пакетов: оба направления теперь включены в закреплённый фильтр WinDivert.

В одном процессе `winws2` работают два профиля. Основной `multisplit` использует обучаемый список; альтернативный `multidisorder` применяется только к доменам, отдельно внесённым в приватный локальный список. Список перечитывается оригинальным движком без его перезапуска.

Пока открыто окно Bypass Manager, фоновая проверка выполняется каждые 60 секунд. Если общее HTTPS-подключение доступно, приложение может взять новый домен из собственного обучаемого списка. После двух отказов TLS в исходном режиме оно временно назначает ему альтернативную стратегию и проверяет TLS дважды. При двух успешных TLS-соединениях выбор сохраняется как **кандидат** для этого домена. При неудаче, отмене или закрытии окна временное изменение откатывается. На один сеанс ограничено число проб. Прерванная операция восстанавливается по приватному журналу после следующего запуска.

## Что именно подтверждено

Исходные Go-проверки оценивают случаи успеха, отказа, отмены и восстановления списка после прерывания. Публичный Windows CI проверяет оригинальные двоичные компоненты, принятие аргументов обоих профилей, запуск WinDivert и путь кнопок «Включить» → HTTPS до/после → «Выключить». Подтверждение корректности этого маршрута не означает, что конкретный заблокированный ресурс удалось открыть.

Ограничения: обрабатывается прежде всего TCP/443 с TLS, а не QUIC/UDP, произвольные протоколы или блокировки по IP. TLS-handshake программы не доказывает доступность веб-страницы в браузере или работы стороннего ПО. Локальная DPI-адаптация **не скрывает внешний IP** и не создаёт VPN. Серверы проверки видят IP приложения.

При закрытом окне запущенный фильтр остаётся активным, но **периодический мониторинг и автоматический подбор прекращаются**. Для возобновления этих функций откройте Bypass Manager. Это неподписанная Alpha; реальные пользовательские сети и приложения ещё требуют отдельных испытаний.
