# Сборка Bypass Manager 0.3 Alpha

Исходники: `Faust-S/knowledge/tools/bypass-manager` в собственной рабочей ветке.

```bash
cd tools/bypass-manager
go test -count=1 ./...
go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags='-H windowsgui -s -w' -o Bypass-Manager.exe .
sha256sum Bypass-Manager.exe
```

Кросс-компиляция под Linux выдаёт только PE-файл. Она не заменяет запуск на Windows.

Проверка в GitHub Actions (публичный репозиторий): `.github/workflows/bypass-manager-windows.yml`. Windows runner выполняет Go tests, PowerShell parse и upstream dry-run без перехвата пакетов. Для полноценного испытания понадобятся настоящие Windows, отдельно установленная Amnezia и разрешённое внешнее подключение. Публичные Actions не получают приватные VPN-ключи.

Программа не содержит GUI веб-браузера и не требует WebView2. Окно реализовано штатным Win32 API через Go, без GUI-фреймворка. Один EXE включает только исходники менеджера, PowerShell-обвязку и метаданные профилей. Оригинальный winws2 устанавливается при согласии пользователя либо заранее.

### Квалификация путей с пробелами и офлайн-каталога

Один exe + VPN-клиент не означает отказа от оригинального движка: 
`winws2`, WinDivert и Lua должны находиться в локальной папке `engine/` или скачиваться по подтверждению пользователя.

`Tests/Verify-Windows.ps1 -WithUpstream -BundleRoot <путь>` проверяет не только WinDivert-фильтры и Lua, но и процессный запуск оригинального `winws2` из пути с пробелами через PowerShell 5.1, без перехвата трафика. Отдельный тест проверяет, что предпочтение отдаётся полному верифицированному `engine/` рядом с EXE.

### Критерии дополнительной проверки приватности

Тестирование на фикстурах: недоступный маршрут к внешнему узлу отклоняется; NONE можно испытать без `winws2`; журнал ограничен 512 измерениями; неизменный публичный IPv6 выявляется как возможная утечка, но другой IPv6 не считается доказательством анонимности. Реальные Windows DPI-пакеты и DNS/WebRTC не исследуются на CI.

### Проверка DNS-маршрутов без VPN-ключей

Тест `Tests/Test-DnsExposure.ps1` выполняется в Windows CI. Он проверяет только чтение настроенных DNS-серверов и их маршрутов на тестовом сетевом интерфейсе Windows; DNS-запросы не посылаются. Не интерпретировать результат как отсутствие утечек. IPv6 HTTP-проба принудительно использует `tcp6`; есть регрессионный unit-тест отсутствия IPv4 fallback.

## Регрессия Windows: маршрут и консоль

Проверка Windows CI выполняет `Tests/Test-EndpointRoute.ps1`: воспроизводит ответ `Find-NetRoute` с двумя объектами, отсутствие маршрута и ошибку получения данных, затем запрашивает фактический маршрут на Windows runner (без передачи пакетов). `process_window_windows_test.go` проверяет, что дочерний PowerShell запускается с `HideWindow` и `CREATE_NO_WINDOW`.

Проверка не подтверждает успешную работу с конкретным VPN-сервером или динамическую смену IP. Для этого нужен настоящий совместимый VPN-клиент и разрешённое подключение.

## Повторная квалификация добавленных измерений

На Linux: `go test -race -count=1 ./...`, `go vet ./...`, `GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags='-H windowsgui' -o Bypass-Manager.exe .`.

На настоящей Windows: `Tests/Verify-Windows.ps1`, `Tests/Test-PathEvidence.ps1`, `Tests/Test-NetworkHealth.ps1`, `Tests/Test-GuiSmoke.ps1`. Новый ICMP-скрипт не требует положительного ответа: отсутствие ответа не считается доказанной потерей. Windows CI не использует подключение Premium, не включает пакетный перехват и не выполняет 15-минутный пользовательский просмотр. Нужна отдельная полевая приёмка.

Для диагностики сначала выполняется быстрый тест при **выключенном VPN**, затем при подключённом Amnezia. Программа показывает внешний IP и приблизительную геолокацию локально, но экспортирует только обезличенное сравнение. Скорость можно перепроверить по кнопке. Для длительной проверки включите видео в браузере, нажмите «Тест видео: 15 мин» и после окончания укажите факт остановок. Нажмите «Собрать отчёт» и передайте `results/latest-support.json`. Не передавайте `settings.json`, `private-direct-baseline.json`, `active/`, дампы драйвера и файлы VPN-клиента.
