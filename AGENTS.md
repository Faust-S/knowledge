# IWXA Specialized Agents — правила разработки

**Предмет:** каталог готовых специализированных агентных решений: комбинации workflow/process, промптов/ролей, алгоритмов/ветвлений, инструментов, критериев результата. Не подменять каталог подборкой программ Goose/Aider/Cline/OpenHands, не создавать общую базу знаний, 12 классов, O*NET/ОКЗ пакеты и второй Core.

Искать в реальных workflow/agent marketplaces и исходных репозиториях, получать точные файлы и версии каждого решения. Выяснять лицензии и источник, запрещать неявное копирование. Стадии LISTING_SCREENED → SOURCE_INSPECTED → ADAPTED_NOT_EXECUTED → TASK_TESTED → IWXA_VERIFIED. Бейдж автора или чужого marketplace не равен проверке IWXA. Настоящее агентное выполнение и проверяемый Result обязательны для VERIFIED.

Изолированный пользовательский контекст формируется Task Discovery/Context Compiler, а разрешения и исполнение остаются в действующем Personal Agent AgentRuntimePort/ToolRuntime. Исходный workflow может содержать API или внешние эффекты: до разрешения и проверки их не запускать.

Разрабатывать один полноценный специализированный агент за раз, от исходника до реального теста, не плодить карточки оболочек. В публичном репозитории хранить только разрешённые ссылки/метаданные, собственные адаптации и синтетические данные; приватные исследования — в Faust-S/IWXA-knowledge.

Текущий исходный пример meeting-followup — авторски адаптированная неисполненная схема, а не рабочий агент. Не повышать статус без реально исполненной задачи через существующий runtime.

## Объединённая открытая исследовательская область — 03.11.2026

Основным объектом библиотеки остаётся **специализированное агентное решение**, не каталог программ. Дополнительно допускаются отдельные *публичные* эксперименты Task Discovery/U1, Cross-Lab, Agent Platforms/Execution и Task→Result conformance. Это **не перенос владельцев исполняемого кода**.

- `Faust-S/iwxa` сохраняет Task Discovery/U1/Context Compiler/Cross-Lab source; публично размещать только лицензированные открытые источники, собственные воспроизводимые алгоритмы и синтетические тесты.
- `Faust-S/iwxa-personal-agent` сохраняет Task/Goal/Graph/Skills/Runtime/ToolRuntime/Human Review/Result. Не создавать второй Task Engine, Core, Graph, Memory или Runtime.
- `Faust-S/T3` сохраняет R5-C4/Access, Reconciliation, Host/Journal/Store, `.iwxa` exchange. НЕ переносить T3 source в каталог ради CI.
- Admin Center владеет организационным поручением/решением; Publisher — лицензиями, релизами и издательским доверием. Не создавать один продукт из трёх.
- `Faust-S/IWXA-knowledge` — закрытая интеграционная карта, а не параллельная исполнительная среда.

Публичные Actions допускаются только для открытых файлов текущего репозитория; не копировать закрытый код и приватные evidence, не применять токены для извлечения private repos. Отсутствие собственной утверждённой LICENSE не означает открытой лицензии только из-за public GitHub; точные лицензии и NOTICE проверять перед распространением. `SOURCE_ONLY` или PASS статических тестов **не повышают** agent solution в TASK_TESTED/IWXA_VERIFIED и не подтверждают продуктовый E2E.
