# IWXA — публичная граница результатов Personal Agent и T3

Дата 2026-11-03. Статус: сравнение интерфейсов; продуктовый обмен не квалифицирован.

## Владельцы

Personal Agent владеет личной Task/Result, моделью/Skills, Human Review, сохранением и повторным использованием. T3 владеет существующим .iwxa Exchange/Reconciliation для межсубъектного обмена. Admin владеет отдельным корпоративным решением о принятии и применении. Publisher выпускает лицензии и не нужен для каждой личной задачи. Knowledge исследует и документирует связи, не создаёт ещё один Store или Task Engine.

## Выявленные ограничения

- Идентификатор личной задачи и digest личного результата не являются автоматически подписанной ревизией организационной Task.
- Общее расширение файла .iwxa не доказывает совместимость профилей.
- Черновик или рекомендация модели не равны выполненному внешнему действию.
- Ревизии результата и ревизии исходной Task имеют разные причинные связи.
- Без подтверждённого организационного назначения нельзя создавать фиктивную Task ради демонстрации успешного обмена.
- Обычная личная Task не требует T3, Admin или обязательного сложного графа.

## Открытый сценарий для дальнейшего исследования

Реальная личная Task -> модель/Skills -> проверяемый Result -> Human Review -> сохранение/reopen -> явный выбор данных для передачи -> существующее организационное назначение -> поддерживаемый .iwxa профиль -> независимое Admin решение -> сохранение/readback -> использование Result в следующей Task.

Это план межпродуктной приёмки, НЕ заявление о реализации. Публичные тесты допускают только публикуемый синтетический или разрешённый материал; приватный код/ключи/данные не переносить. Прямое сквозное исполнение PA -> T3 -> Admin пока NOT_TESTED. Узкая локальная проверка границ T3-контракта в owning репозитории: 6/6, без готовности продукта.
