# Activity + D05 CehoVod: исходные факты и оригинальный T3 D2

Источник модели: Faust-S/cehovod.ru, commit 0ada4f082a39ec9a7bf2be3f75b57ebc5ebc39b4, tree a0570f59cf74a4f6449d4cf874a288fc898fdc29.

В исходном оригинальном T2 Host домена CehoVod объявлены 26 типов Result версии 1.0.0 и ровно три типа Kernel-событий: cehovod.result.saved, cehovod.order.transitioned, cehovod.operation.transitioned.

Профиль d05-t3-evidence-binding.mjs передает этот список ОРИГИНАЛЬНОМУ D2 T3 0.3.0. Все три вида событий имеют epistemic_status=reported. Подписанная запись в Kernel не доказывает фактическую резку, гибку, измерение или приемку. Объекты типа operation остаются техническими Result, а не автоматически наблюденной Activity. Связи based_on берутся из оригинальных Kernel relations, строковые ID payload не превращаются в доказанные E2O-ребра.

В тесте test_activity_d05_t3_evidence.mjs использован модельный CASE-001 формата CehoVod с количеством 120 только как фикстура. Публичный CI проверяет зафиксированную структуру D05, действующий signed D1/D2 read, отказ после отзыва, привязку к Workspace, сохранность данных и HOLD для сообщенных этапов, редких связей и неизвестных событий.

Это НЕ свидетельствует о производстве 120 деталей, установленном оригинальном корпоративном Host в Activity, независимом подтверждении хозяйственных операций, анонимности, соответствии полному OCEL2 или разрешенном обмене .iwxa.

Для коммерческой квалификации требуется исполнить штатный CehoVod CASE-001 через оригинальный T2/Host с сохраненными результатами, актами и QC, подтвердить их независимым чтением и получить отдельную версионированную привязку истинно наблюдаемых бизнес-событий от владельца предметной системы. Activity не вправе самостоятельно повышать reported до observed.

Проверка полного совпадения с исходными TS-файлами D05 выполняется отдельно при явно предоставленном авторизованном локальном checkout через IWXA_D05_SITE_SOURCE_DIR. Публичный GitHub Actions не использует приватный D05 repo или токены. Статический pin не равен автоматически подтверждённой актуальности исходного сайта.
