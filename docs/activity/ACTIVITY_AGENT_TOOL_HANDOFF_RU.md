Не создавать второй ToolProviderPort, Task/Result, хранилище, очередь, IAM, подписанта или Exchange. Activity предоставляет только локальные предметные операции. Agent владеет Task, проверкой источника, подтверждённым планом, исполнением и восстановлением результата.

В inspected Agent work/2026-11-24-agent-process-modeling (3b431260f3709ba0ed46d35556d124c39f9f37ab) уже есть runtime/r4pm_program.py: проверка принятой Task, точного plan_digest, provider binding, idempotency, accepted_artifact_ref, состава projection, digest и bytes источника. Поэтому Activity предоставляет тонкий мост file-to-stdin, а не отдельный исполнитель.

## Точка подключения

Пакет Activity берётся из одной проверенной ревизии публичного Faust-S/knowledge, включая tools и modules/activity-base-anonymizer; Agent проверяет manifest и digest установленного пакета. Не скачивать код или языковые модели во время обработки Task. В штатной установке использовать изолированный Python и Node 22+, установленные версии инструментов. ARX 3.9.2 требует Java 21 и оригинальный libarx с SHA-256 18040108e95ca7955d806bf32354b20601d664495653b8ee169d249f43f58d44. OpenDP 0.16.0; SimPy 4.1.2; Presidio 2.2.366, en/ru spaCy 3.8.0.

Программный шаблон: фиксированная операция, исполняемый python, argv [-I, <проверенный путь tools/activity-agent-input.py>, --run, <операция>, {source}, {digest}]. На этапе подключения: [-I, <тот же путь>, --probe, <операция>]; ожидаемый токен iwxa-activity-<operation-with-hyphens>-v1. Для разных внешних зависимостей проверять доступность отдельно. Путь и digest подставляет доверенный адаптер после разрешения source reference оригинальной принятой Task; не публиковать путь в аргументах для пользователя или LLM.

Создать TemporaryDirectory(prefix='iwxa-activity-') в локальной среде Agent; записать проверенные байты в input.json, вызвать оригинальный U01 с source=этот файл и digest=sha256 этих байтов. По завершении убрать временную копию. Мост читает один раз, сверяет digest, передаёт exact bytes штатному Activity worker через stdin, возвращает его exact stdout. HOLD exit 2 не считать выполненным или принятым. Мост не устанавливает права, это делает существующий Agent. Ограничение: 8 МБ вход, 4 МБ результат, 18 с внутренний worker; исходный U01 остаётся с 20 с. Длительные анализы использовать только через штатный механизм длительных программных операций Agent после отдельной квалификации; не ослаблять лимит и не подменять результат тайм-аутом.

## Критерии совместной приёмки

1. Использовать настоящий Task source resolver и оригинальный ToolProviderPort. Неверный Task/план/Workspace/digest не запускает worker.
2. Выполнить реальные upstream Presidio en/ru, ARX, OpenDP, SimPy; показать точный результат в существующей Activity.
3. После перезапуска открыть исходный Task и exact сохранённые запрос/ответ. Изменённый технологический кандидат делает прежний результат неприменимым.
4. Проверить недоступную зависимость, превышение времени, отмену, HOLD, отсутствие результата, несовпадение редакции. Не считать успешный CLI exit предметной приёмкой.
5. Кандидат может быть неполным, результаты модели не являются физическим исполнением. Право раскрытия, повторный бюджет приватности и Exchange остаются самостоятельными стадиями.
6. Приватный Agent Actions не запускать. Для исходных публичных адаптеров используется квалификация в Faust-S/knowledge; приватный код не копировать в публичный репозиторий. Совместную установленную квалификацию проводить согласованным маршрутом владельца.
