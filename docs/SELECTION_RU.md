# IWXA Specialized Agent Library — действительный объект проекта

**Объект:** самостоятельное СПЕЦИАЛИЗИРОВАННОЕ АГЕНТНОЕ РЕШЕНИЕ, а не самостоятельная программа-рантайм и не общий prompt. Оно содержит процесс, промпты, алгоритм/правила перехода, инструменты и зависимости, входные требования, результаты, условия остановки и проверку. У решения может быть одна или несколько ролей и несколько этапов, при этом оно должно переноситься в действующий IWXA Personal Agent через разрешённый интерфейс.

## Что искать
Источники: marketplace готовых агентов и сценариев (Dify Marketplace, n8n templates, Flowise template marketplace, Agent Library у разработчиков), реальные готовые crews/flows с исходниками на GitHub. Нужны конкретные workflow/agent IDs и файлы, не ссылки на платформы и не коллекции промптов.

## Этапы оценки
- **LISTING_SCREENED**: публичная карточка с конкретной задачей, описанием процесса и зависимостей. Ещё нет исходных workflow bytes и права на повторное распространение.
- **SOURCE_INSPECTED**: получен и просмотрен настоящий экспорт/исходник всего агентного решения с версиями, правами, внешними эффектами и входными интерфейсами.
- **ADAPTED_NOT_EXECUTED**: цельная рабочая конфигурация IWXA (process + prompts + tools + output) собрана, но НЕ исполнена. Это не выпуск.
- **TASK_TESTED**: реальные позитивные и негативные задачи выполнены на точной конфигурации со свидетельствами результата, отдельно оцениваются новые ошибки/необходимые вмешательства.
- **IWXA_VERIFIED**: решение показало воспроизводимый результат внутри *существующего* AgentRuntimePort / ToolRuntime с минимальными правами, Human Review, readback, restart. Сертификат ограничен версией/средой/входами/приватностью.

## Отсев
Один красивый prompt ≠ агент. Пакет с набором заголовков ≠ агент. Программа Goose или Dify как software runtime ≠ специализированный агент библиотеки. Рекламный бейдж «Verified by a partner» в другом магазине ≠ IWXA_VERIFIED. Приложение с сетевыми вызовами без раскрытия, скрытые полномочия, без исходников/прав на копирование, недостающие критические шаги → HOLD/REJECT.

Проверяем полные процессы, а не обязательно всю платформу: считываем настоящий файл, восстанавливаем DAG и развилки, отделяем инструкции от данных и API-key placeholders, видим внешние side effects, затем импортируем/адаптируем к действующей модели IWXA. История лицензий: проверяется отдельная возможность *ссылки*, *копирования*, *изменения* и *распространения*.

## Реальный продукт
Каталог предметных агентных решений. Каждый агент включает подходящую область задач и тесты; классификация функций — лишь способ найти агента. Перед запуском Task Discovery/Context Compiler собирают достаточный контекст конкретного человека. AgentRuntimePort, ToolRuntime и Human Review — единственные владельцы исполнения и полномочий.

Проверка: минимум несколько независимых положительных задач, повторяемость, отрицательные случаи по мере риска, сравнение с обычной моделью с доступными инструментами. Критический провал безопасности блокирует выпуск, даже если остальные тесты зелёные.

## Pilot status
В каталоге: 1 source-inspected и авторски адаптированный **неисполненный** CrewAI meeting agent; 2 listing-screened Dify workflow. **0 IWXA_VERIFIED.** Нельзя заявлять работу с Trello/Slack или правом на издание исходного workflow; оба отдельно контролируются. Эта стадия показывает правильный объект, но ещё не завершённое испытание агента.
