# Программы vs специализированные агенты

- **Платформа:** IWXA Personal Agent, CrewAI, Dify, n8n, Flowise, Goose — среда исполнения/поставщик инструментов. Они не являются основными строками данного каталога.
- **Агент:** «анализ совещания и подготовка проверяемых поручений», «конкурентная разведка», «юридический поиск», «обработка заявки», с собственными шагами и правилами принятия решений.
- **Сведения конкретного человека:** документы, исходный контекст, права и критерии — собираются через уже существующие IWXA U1/Task Discovery/Context Compiler; не входят в общий пакет.
- **Capabilities:** атрибуты специализированного агента и критерии маршрутизации, **не самостоятельная база**.
- **Рабочая модель:** выбрать agent solution → выяснить требуемые ему входы → собрать разрешённый контекст → AgentRuntimePort/ToolRuntime → реально исполнить → Human Review → Result/readback. Не копировать чужую платформу в отдельный Core.

Важно: адаптация CrewAI source example не может автоматически создавать Task, писать Trello/Slack или использовать учетную запись человека. В текущем прототипе эти эффекты удалены и требуют отдельного штатного разрешения IWXA после последующей интеграции.

После получения правообладательских условий можно решать, переносить ли полные исходные workflow байты, хранить ли только ссылки или публиковать свою полностью авторскую адаптацию. До этого не распространять чужой workflow как собственный продукт.
