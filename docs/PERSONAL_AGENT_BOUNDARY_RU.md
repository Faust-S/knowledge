# IWXA: как библиотека используется без второго runtime

Источник истины о **доступных и установленных программах** — существующий Personal Agent Programs/Connections. О правах — ToolRuntime / Storage Authority; о Task/Result и сохранении — существующий Core; об агентах и маршруте — существующий AgentRuntimePort; о пользовательской ситуации — Task Discovery, U1 и Context Compiler. Внешняя библиотека не заменяет эти компоненты.

Каталог этой работы содержит **кандидатов агентов** и результаты внешних квалификационных испытаний. На этапе внедрения должен быть реализован тонкий *read-only импорт* разрешённых описаний в существующий раздел «Возможности → Помощники/Программы»; это пока не реализованная интеграция, а ограниченная задача.

Формирование задания: Task Discovery получает цель человека, существующий Context Compiler определяет достаточность контекста. Выбранный агент получает только необходимые разрешённые данные, инструкции его сценария, явные запреты и критерий результата. Библиотека агента определяет **свои входные требования**; данные владельца не копируются в публичную базу.

**Goose:** существующий `adapters/goose_local_cli.py` допускает только PUBLIC/SYNTHETIC и действует в режиме proposal-only/no-tool. Нельзя объявлять полноценного Goose исполнителем PRIVATE или задействовать внутренние инструменты без штатных разрешений. Никаких изменений в `Faust-S/iwxa-personal-agent`, T0/T1 или в Cross-Lab в рамках этого репозитория.

Остальные Aider/OpenHands/Cline: отсутствие проверенного IWXA-adapter = NOT_IMPLEMENTED; карточка не запускает программу и не выставляет install-ready.
