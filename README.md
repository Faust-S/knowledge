# IWXA Knowledge — открытые исследования задач и специализированных решений

Публичный репозиторий разработки **единого маршрута решения задач IWXA**: от проблемы/цели человека через обнаружение Task, выбор способа решения и контекста до проверяемого Result. Не универсальная база пользовательских знаний и не второй Personal Agent.

## Единый маршрут

1. **Человек и его задача:** Problem / Goal → Task Discovery · Activity Research · U1 (если нужны) → конкретная Task и критерии результата.
2. **Подготовка решения:** подходящий **Agent Solution** либо **обычная модель + Skills** → Knowledge/Context Compiler/Cross-Lab по необходимости → Plan/Graph, ветвления/циклы только когда полезны.
3. **Выполнение и продолжение:** существующий Runtime (модель, AgentRuntimePort, ToolRuntime, программы) → Execution → Result/Human Review → сохранение, восстановление, Memory.

**T0/T1, Evidence и Provenance** дают смысловую основу. Эти уровни логические, а не отдельные продукты. Для уже ясной Task допустим короткий путь сразу к решению.

## Действующие направления

- `catalog/solutions/` и `solutions/`: конкретные специализированные агентные решения и авторские адаптации. Текущий `meeting-followup` — **ADAPTED_NOT_EXECUTED**, два Dify — listings; **IWXA_VERIFIED=0** до исполнения с настоящим Result.
- `tests/` и `tools/`: адресные тесты и квалификация решений. Статические и атрибуционные проверки не заменяют настоящего исполнения.
- **Task Discovery / Cross-Lab / TASK-EXP-01:** готовится перенос *открытых адаптеров, воспроизводимых экспериментов и разрешённых метаданных*. Пока **исходные и действующие** U1/E1–E4, R1–R4, Context Compiler, TASK-EXP-01 остаются в `Faust-S/iwxa` и их миграция не считается завершённой.

**Публичность репозитория не снимает требований к праву публикации.** В GitHub допускаются только разрешённые исходники/адаптеры, открытые метаданные, собственные тесты и обезличенные результаты. Приватные данные, закрытый код и необъявленные источники — только у владельцев.

Для воспроизведения допустимы обычные публичные GitHub Actions без приватных credentials. Научные результаты отделять от инженерного PASS, а независимый human gold — от авторских/синтетических меток. Продуктовая Task/Graph/Result реализуется в Personal Agent.
