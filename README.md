# IWXA — библиотека специализированных агентных решений

**Не каталог приложений Goose/Aider/OpenHands/Cline.** Основной объект — готовый для изучения и последующей квалификации специализированный агент: цель + рабочий процесс + промпты/роли + алгоритм + инструменты и входные требования + конкретный результат + тесты.

В библиотеке появляются решения из настоящих магазинов/репозиториев workflow: CrewAI examples, Dify Marketplace, n8n workflow templates, Flowise templates. Программа-исполнитель — зависимость решения, а не самостоятельный агент каталога. Данные конкретного человека получает существующий Personal Agent при выполнении, не общая база.

Сейчас проведено исследование реальных источников: 1 исходный CrewAI meeting-flow с настоящими YAML и Python, 2 конкретных Dify marketplace templates. Для meeting-flow создана **собственная адаптированная схема** без неразрешённых внешних эффектов. Она НЕ проверена исполнением. **IWXA_VERIFIED: 0**; не путать с чужим статусом marketplace.

## Содержание
- `catalog/solutions/` — 3 конкретных специализированных решения, их источники, статусы и ограничения
- `solutions/meeting-followup/agent.json` — цельная оригинальная схема шагов/промптов/результатов
- `tools/check_catalog.py` — запрет ложного VERIFIED и неполных схем
- `tests/test_catalog.py` — негативные тесты для структуры, не тесты реального исполнения
- `docs/SELECTION_RU.md` — методика отбора из магазинов и проверок
- `docs/BOUNDARIES_RU.md` — разделение специализированного агента, программы и контекста

**Существующие IWXA AgentRuntimePort, ToolRuntime, Task Discovery, Context Compiler, Programs Center не дублируем.** Публичные материалы не включают приватные данные, токены, копии исходного кода CrewAI или Dify YAML без удостоверения прав.
