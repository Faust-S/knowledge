# Three local model profiles: candidate and replacement contract

Base: 3056eef0665fb3503294d49b89d937af2ea060e2. This branch is not a new T3 release. No alteration to release/club-stable or installed users.

The single shared developer entry is integration-sources/bli1/catalog.mjs. MODEL_PROFILES defines light / balanced / extended. Each selects one family (currently Qwen2.5 Instruct 0.5B / 1.5B / 7B), with FP16/FP32 variants of four-bit quantization as technical alternatives, not separate user profiles. Apache-2.0 originals: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct, https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct, https://huggingface.co/Qwen/Qwen2.5-7B-Instruct. Language and practical quality remain test gates. Original SmolLM2 entries remain legacy technical choices for compatibility.

Replacement procedure: preserve stable profile IDs and replace its family and exact variant records from the compatible pinned WebLLM package. Do not change domain code, the shared engine, user records, or caches merely because of a family upgrade. The domain build automatically derives the exact model-install allowlist for the original Service Worker. Increment MODEL_CATALOG_VERSION, run `node scripts/t3-model-catalog.mjs --refresh-pin` to update only the catalog source pin, run source, upstream package, physical GPU, quality and cold offline restart tests, then release/import qualified T3. An engine or model format change is a separate compatibility change, not just a catalog substitution. Never silently download, replace, or delete the previously installed model. The legacy entries must not expand the ordinary user profile selector. Keep old models accessible for an explicit transition where required.

Download: weights/tokenizer/config from the selected MLC repository on Hugging Face; matching prebuilt WebGPU WASM from raw.githubusercontent.com/mlc-ai/binary-mlc-llm-libs. WebLLM remains the only cache owner. New Qwen profiles pin the full Hugging Face model commit and GitHub WASM repository commit. Upstream WebLLM `cleanModelUrl` respects an explicit /resolve/<revision>/ base; the same original WebLLM cache now separates model revisions by URL. Legacy SmolLM2 retains released main URLs for compatibility. Revision pins are not a byte-integrity attestation. A future mirror requires qualified immutable copies and license/redistribution notices; no mirror has been deployed. No weights are shipped in the website dist; no cloud inference or fallback. Installation requires explicit consent. Ordinary inference uses local assets and is cache-only. Origin-scoped browser cache can be evicted, and different domains may need their own cached copy.

Source acceptance is distinct from actual Android/iOS browser generation, measured transfer/cache bytes, real Russian form accuracy, and native/PWA/offline restart. Keep 0.3.0 pinned in Club until the next T3 candidate is independently accepted. No second Core, Store, Host, model cache or inference engine is introduced.

Published repository sizes on 24.11.2026: 290 MB (0.5B), 880 MB (1.5B), 4.3 GB (7B), plus a 5-7 MB library. Catalog uses rounded 300 MB / 900 MB / 4.4 GB planning estimates, not a measured transfer or precise browser storage requirement. Source: each exact MLC Hugging Face tree and pinned GitHub library directory. Storage headroom is a soft warning and actual device load is decisive.
