# Three local model profiles: candidate and replacement contract

Base: 3056eef0665fb3503294d49b89d937af2ea060e2. This branch is not a new T3 release. No alteration to release/club-stable or installed users.

The single shared developer entry is integration-sources/bli1/catalog.mjs. MODEL_PROFILES defines light / balanced / extended. Each selects one family (currently Qwen2.5 Instruct 0.5B / 1.5B / 7B), with FP16/FP32 variants of four-bit quantization as technical alternatives, not separate user profiles. Apache-2.0 originals: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct, https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct, https://huggingface.co/Qwen/Qwen2.5-7B-Instruct. Language and practical quality remain test gates. Original SmolLM2 entries remain legacy technical choices for compatibility.

Replacement procedure: preserve stable profile IDs and replace its family and exact variant records from the compatible pinned WebLLM package. Do not change domain code, the shared engine, user records, or caches merely because of a family upgrade. The domain build automatically derives the exact model-install allowlist for the original Service Worker. Increment MODEL_CATALOG_VERSION, update the existing source pin, run source, upstream package, physical GPU, quality and cold offline restart tests, then release/import qualified T3. An engine or model format change is a separate compatibility change, not just a catalog substitution. Never silently download, replace, or delete the previously installed model. The legacy entries must not expand the ordinary user profile selector. Keep old models accessible for an explicit transition where required.

Download: weights/tokenizer/config from the selected MLC repository on Hugging Face; matching prebuilt WebGPU WASM from raw.githubusercontent.com/mlc-ai/binary-mlc-llm-libs. WebLLM remains the only cache owner. Catalog stores exact current upstream URLs, not immutable content digests; upstream main is mutable. Before production mirror or immutable source release, record revisions/checksums and verify original WebLLM URL compatibility, licensing and redistribution. No weights are shipped in the website dist; no cloud inference or fallback. Installation requires explicit consent. Ordinary inference uses local assets and is cache-only. Origin-scoped browser cache can be evicted, and different domains may need their own cached copy.

Source acceptance is distinct from actual Android/iOS browser generation, measured transfer/cache bytes, real Russian form accuracy, and native/PWA/offline restart. Keep 0.3.0 pinned in Club until the next T3 candidate is independently accepted. No second Core, Store, Host, model cache or inference engine is introduced.
