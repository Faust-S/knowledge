## Дополнение 14.11.2026: штатный изолированный D3 транспорт к оригинальному native owner

**Точный source owner и механизм:**
- \`src/t3/original-control-http-handler.mjs\` расширяет прежний уже защищённый Control HTTP единственной опциональной native границей \`reconciliationPortFor({contextEpoch})\`, возвращающей **существующий оригинальный Host-порт** (приём \`.iwxa\`, preview, ACCEPT/REJECT, selected application, отдельный Apply). - \`src/main-isolated-signed-workspace.tsx\`, \`src/App.tsx\`, \`src/shell/AppShell.tsx\`, \`src/workspace-host/runtime/*\` подключают port к существующему \`WorkspaceHostRuntimeHandle.reconciliation\` только если доверенный native owner сообщает \`available:true\`.
