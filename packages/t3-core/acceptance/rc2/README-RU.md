# IWXA T3 0.3.1-rc.2: запуск для независимой приёмки

Это готовый локальный экземпляр **оригинального** опубликованного Host, не новая версия платформы и не имитация. Внутри один dist, оригинальный Kernel 0.3.6 / Contract 1.3.0, один compiled BLI и Windows x64 Node.js для статической HTTPS-раздачи. Модели не входят.

1. Распакуйте весь ZIP в отдельную папку. Запустите START.cmd. Сборка, npm, Git и установка Node не нужны.
2. Прочитайте запрос о временном сертификате localhost. Только при согласии введите YES и подтвердите стандартное окно Windows, если оно появится. Сертификат действует два дня, создаётся для localhost и добавляется только в CurrentUser Root. Не требуется отключать проверку HTTPS. Запуск PowerShell использует ExecutionPolicy Bypass только для текущего процесса, не меняет политику ОС.
3. Держите окно запуска открытым. В браузере **этого же компьютера** откройте https://localhost:18443/workspace/. В удалённом браузере Codex этот loopback может быть недоступен; в таком случае нельзя считать его запущенным на той же машине. Для удалённой приёмки нужен отдельный HTTPS origin, на котором развёрнут этот же dist с точной конфигурацией origin.
4. Проверьте создание рабочей области, навигацию, Exchange, Lifecycle. Включите переключатель T3 отдельно, убедитесь в готовности автономного режима. Откройте оригинальную локальную модель, выберите Workspace, установите модель только по явному согласию, получите и сохраните черновик через Kernel.
5. Файл examples/workspace-original.iwxa создан реальным оригинальным Kernel при проверке поставки. Импортируйте его штатным Exchange; откройте сохранённые документы, историю и вложение. Экспортируйте всю Workspace, перенесите в независимый профиль браузера. Не используйте реальные конфиденциальные документы в этой приёмке.
6. Полностью закройте браузер, отключите сеть, откройте тот же URL в том же профиле; проверьте восстановление модели из кеша, новую генерацию и новое сохранение. Для теста холодного браузера оставьте локальный HTTPS сервер работающим. Для проверки полного offline site можно остановить сервер после установки автономии, если браузер не потерял доверие к сертификату; не смешивайте это с проверкой удаления TLS сертификата.
7. Ctrl+C завершает локальную раздачу. При нормальном завершении удаляется созданный временный сертификат, но браузерные Workspace и model cache не удаляются. Если процесс был аварийно завершён, в certmgr.msc в Current User / Personal и Trusted Root Certification Authorities может остаться сертификат с именем IWXA T3 temporary localhost acceptance; удалите только сертификат этого теста. Не меняйте глобальные настройки безопасности.
