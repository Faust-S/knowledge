# IWXA T3 0.3.1-rc.5: локальная независимая приёмка без сертификатов

Этот отдельный комплект предназначен только для локальной приёмки. Исполняемые Host, BLI, Kernel 0.3.6 и Contract 1.3.0 взяты из опубликованной платформы, не компилировались заново. Для localhost использована предусмотренная оригинальной схемой конфигурация HTTP loopback. Опубликованные сайты по-прежнему используют HTTPS. Не переносите этот локальный адрес на внешний сервер.

1. Распакуйте весь архив. Запустите START.cmd. Внутри официальный Node.js Windows x64; PowerShell, Cert:, npm, Git, права администратора, временные сертификаты и изменение настроек браузера не нужны.
2. После сообщения T3_RC5_LOCAL_LOOPBACK_READY откройте во встроенном браузере http://localhost:18443/workspace/ на этой же машине.
3. Если START.cmd невозможно запустить через оболочку, вызовите runtime\node.exe serve-acceptance.mjs из распакованной папки. Не изменяйте настройки безопасности и не используйте внешний браузер вместо встроенного Codex.
4. Сервер слушает только 127.0.0.1, принимает только Host localhost:18443. Если встроенный браузер расположен на другой машине и не видит localhost, зафиксируйте BLOCKED и предоставьте доступный заранее настроенный HTTPS origin; не создавайте туннель.
5. Проверьте Workspace, Exchange, Lifecycle и оригинальный examples/workspace-original.iwxa. Явно включите T3, проверьте cold/offline. Установка локальной модели только по вашему согласию; веса не включены. Обычный браузер рассматривает localhost как secure context; приёмка должна подтвердить это фактически.
6. Завершение: Ctrl+C в окне сервера. Никаких сертификатов не создаётся; данные браузера сохраняются. Это отдельный origin: HTTPS-данные прежнего стенда автоматически не переносятся.
